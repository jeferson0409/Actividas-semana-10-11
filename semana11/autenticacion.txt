El login es el proceso que permite identificar a un usuario antes de darle acceso a una aplicación. Gracias a la autenticación, solo las personas autorizadas pueden acceder a ciertas funciones. Algunas rutas deben estar protegidas porque pueden contener información privada o permitir modificar datos importantes. Esto ayuda a mantener la seguridad del sistema. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
